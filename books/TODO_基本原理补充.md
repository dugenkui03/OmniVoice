## 1. 音素、拼音、音节、声调

需要补充：

- 音素是什么：最小的发音单位。
- 音节是什么：一次比较完整的发音单元，通常由一个或多个音素组成。
- 音素和音节的区别：音素更细，音节更像人实际听到的一拍。
- 中文里的拼音、声母、韵母、声调分别对应什么。
- 英文里的 phoneme、syllable、stress 分别是什么。

简单例子：

```text
中文：
“妈” = ma + 一声
“ma” 可以看成一个音节，里面还能拆出更细的声母 m 和韵母 a。

英文：
cat 可以拆成 /k/ /ae/ /t/ 三个音素。
cat 整体通常是一个音节。
```

对应章节：

- 第 1 章：只做入口解释。
- 第 4 章：详细解释文本前端、音素、拼音、声调。

## 2. 声学模型

需要补充：

- 声学模型是什么：把“发音内容 + 条件”变成中间声学表示的模型。
- 它解决什么问题：决定这句话应该怎么发声。
- 输入通常是什么：文本、音素、拼音、说话人、情绪、风格等条件。
- 输出通常是什么：mel、latent、codec token 等中间声学表示。

简单理解：

```text
谁在说 + 文本/音素 + 说话方式
    ↓
声学模型
    ↓
mel / latent / codec token
```

对应章节：

- 第 1 章：给出一句话直觉。
- 第 8 章：详细解释 encoder、decoder、attention、duration、pitch、energy。

## 3. mel、latent、codec token

需要补充：

- waveform 是最终音频波形。
- mel-spectrogram 是更容易让模型预测的频谱表示。
- latent 是模型内部压缩后的连续表示。
- codec token 是语音编码器压缩出来的 token，可以更适合新一代生成模型。
- 它们都不是“纯内容”或“纯音色”，通常混合了内容、音色、韵律和情绪。

简单理解：

```text
文本/音素
  → 声学模型
  → mel / latent / codec token
  → vocoder 或 decoder
  → waveform
```

对应章节：

- 第 1 章：只解释在系统结构中的位置。
- 第 5 章：详细解释这些声学表示。
- 第 9 章：解释它们如何变成 waveform。
