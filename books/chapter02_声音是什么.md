# 第二章：声音是什么 —— 波形、采样率与频率

本章讲 TTS 最终生成的物理对象：音频波形。理解波形后，后续的 mel、vocoder、扩散去噪才有落点。

## 2.1 波形

数字音频可以看成一串随时间变化的采样点：

```text
x = [x1, x2, x3, ..., xT]
```

每个采样点表示某个时刻的振幅。TTS 最终输出的 `.wav` 文件，本质上就是这条时间序列加上采样率等元信息。

## 2.2 采样率

采样率决定每秒记录多少个采样点：

| 采样率 | 常见场景 |
| --- | --- |
| 16 kHz | 语音识别、电话语音、轻量语音应用 |
| 22.05 kHz | 许多 TTS 训练集和 demo |
| 24 kHz | 现代 TTS 常见高质量配置 |
| 44.1 kHz | 音乐、CD 质量音频 |

采样率越高，潜在音质上限越高，但训练、推理和存储成本也更高。

## 2.3 频率、相位与谐波

需要掌握的基础术语：

```text
amplitude 振幅
frequency 频率
phase 相位
harmonic 谐波
noise 噪声成分
voiced / unvoiced 有声音 / 无声音
```

后续章节会把这些物理概念映射到 F0、formant、mel-spectrogram、vocoder 等模型概念中。
