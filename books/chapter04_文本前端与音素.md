# 第四章：文本前端与音素 —— 文字不是发音

本章讲 TTS 输入模型前需要做什么。很多“读错字”的问题不是模型生成能力不足，而是文本前端没有把文字转换成正确的发音结构。

## 4.1 文本前端的任务

TTS 的文本前端通常包括：

```text
文本规范化
数字、日期、单位读法
分词
多音字消歧
G2P
音素转换
声调标注
韵律边界预测
```

例如：

```text
2026年5月20日
1.5公里
重庆
银行行长
我想学习 TTS。
```

这些输入不能只按字符直接读，需要先确定正确读法和停顿位置。

## 4.2 音素、拼音与声调

英文 TTS 常见术语：

```text
phoneme 音素
grapheme 字符
syllable 音节
stress 重音
```

中文 TTS 常见术语：

```text
拼音
声母
韵母
声调
轻声
儿化
多音字
韵律词
韵律短语
```

## 4.3 本章核心结论

```text
文字不是发音
音素 / 拼音 / 声调才更接近发音
```

很多 TTS 模型使用音素、拼音或 phoneme 序列作为输入，是为了降低发音歧义，让声学模型专注于生成自然语音。
